COP 3350 · Systems Administration & Programming

Lab Overview

Follow a request from a Linux client to one of two websites on the same Apache server.

How the request reaches a site

  1. Resolve the hostname. The client asks BIND for the IP address associated with the requested site. Both site names point to the same web server.
  2. Connect over HTTPS. The browser opens a TLS connection. If the request starts over HTTP, Apache redirects it to HTTPS.
  3. Serve the selected site. Apache uses the hostname to select a virtual host. It serves this overview as HTML and runs PHP for the clock.
